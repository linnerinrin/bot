
# nonebot插件，民间bot框架风控不想玩了，留个档

## 普通功能

**带keyword**

hello *存活测试*

来支持了 *二维码*

xx还是xx *选择*

我的运势 *测运势*

今日老婆 *群友随机选一个，每日更新*

离婚 *取消现在绑定*

xx吃什么 *食物列表抽一个*

xx喝什么 *饮品列表抽一个*

今日天气 xx xx *调api查天气*


**不带keyword**

b站卡片解析 /*发b站链接解析视频，然后下载视频发到对话里*/

入群退群欢迎 /*检测入群退群发消息*/
